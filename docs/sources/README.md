## poteto：Automate Anything with Grok Bot

- 原帖：https://x.com/poteto/status/2123159537016533493（2026-11-18）
- 文章本体：https://x.com/i/article/2122921713864171520
- 本地副本：`raw/poteto-automate-anything.md`（正文完整，配图只有占位），`raw/poteto-automate-anything.fx.json`（抓取时的原始数据，来自公开的 fxtwitter 接口）
- 作者一律称「作者」或「poteto」，不用他 / 她。

要点（按原文顺序）：

1. **自动化是一种思考方式。** 两部分：目标（最后要得到什么）和过程（怎么得到）。例子：烤苹果派、换爆胎。自动化就是把过程交给机器或代码。
2. **Grok Bot 让不写代码的人也能自动化。** 用大白话说要什么，和 bot 一起把步骤想清楚。bot 有自己的电脑：能动鼠标、装和连应用、上网、进会议记笔记。
3. **先想目标。** 新建一个 bot，名字随便起，想不出就叫 Potato，以后让它自己改名。常见错误：把过程当目标（填表、发邮件只是一步）。想想这个过程对生意有什么用：多赚钱还是省成本。别太执着于现有过程，bot 可能找到更好的做法。
   - 提示词：告诉 Potato 它负责的目标，让它按目标给自己起名、选头像。
   - 目标例子：存钱买车买房、给小店排客户预约、让顾客留好评、招人、收集产品反馈、准备周会幻灯片、给产品做新功能。
   - 说不清目标时：让它一个个问题地采访你，直到目标让你满意。
4. **讲清过程。** 最好用语音输入，想到什么说什么。要讲：平时的步骤、要留意什么、用哪些应用和工具、怎么检查做对了、信息从哪来（邮件、Slack/Teams、工单、应用或网站）、反馈从哪来（顾客评价、同事）。
   - 提示词：这是我平时的做法……想想你怎么完全接手。开始前先用简单的话复述你理解的目标和过程，我确认了再说。先别执行，先把过程规划好。
   - 第一遍不用完美：看它复述，补充纠正，几轮以后满意了再让它开工、去连需要的应用。
   - 进阶：让它对照目标审一遍过程，看有没有更好更省事的做法。
5. **教它你怎么判断。** 你做很多事不用想（哪种服务要更久、谁能做、两单之间留空），bot 也需要这些背景。告诉它信息从哪来、怎么检查做完了：邮件和预约系统时间对不上信哪个；发了邮件不等于订好了，要存好预约、给顾客确认；还在等信息就记下来，回头接着做，别重复建预约。
   - 不用一开始讲全：拿几个真实例子，包括出过错的，问它会怎么处理，再给反馈。
   - 提示词：帮我找出我还没告诉你的东西。问我怎么做决定、信息从哪来、怎么检查、什么时候该找我。一次只问一个问题，再带我走几个例子。
6. **让它自己变好。** 给它拿到反馈的应用和工具：比如盯邮件、社交媒体、Google/Yelp 评价，自己提改进建议。例子：Yelp 上有人说等太久，bot 查到评价和当天记录就能看出哪里出了问题。
   - 业务越数字化越好；bot 也能帮你做工具来收集数据（例：修车店记录到店、见到接待、交钥匙、开工、完工的时间）。
   - 用统一的 ID（顾客 ID、邮箱、订单号、零件号、条码、员工号）把不同应用里的数据串起来。
7. **让它自动开工：routine。** 什么时候干：来邮件时、有人发消息时、按固定时间。没有 routine，bot 只在你开口时干活；有了它，你就不再是瓶颈。让 bot 帮你设，它会设。
8. **Dr Eggbot。** 作者把自己会的自动化方法都教给了它。它是「设计 bot 的 bot」，帮你做出高质量的 bot。

本站用到：新手入门三课、完整教程 1–3、5–7 步、「提示词」页。
