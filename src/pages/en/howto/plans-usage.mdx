Grok Bot doesn't need its own subscription. It comes with your plan. What you do need to watch is usage: it's a weekly allowance that resets each week, and the thing that spends it fastest is a routine that runs often. Say you're looking for a place to rent and you're afraid the good ones will go, so you have it check the rental sites every hour. Or you have it watch a Slack channel where people talk from morning to night. <mark>A routine that runs hourly, or watches a busy Slack channel, can use a week's allowance in a day.</mark>

Plans and allowances change, so the official [plan page](https://docs.x.ai/x-subscription/grok-bot) and [FAQ](https://docs.x.ai/grok-bot/faq) are the source of truth, and this page leaves prices out. First check whether your plan includes Grok Bot, then see how usage gets used, where to see it and how to use less, and last what to do when it runs out and how to set a limit.

## Check whether your plan includes it

- **The X Subscription:** **Premium**, **Super** and **Ultra** include Grok Bot, for individuals and team seats. **Plus** and Free don't. Super and Ultra have larger weekly allowances.
- **Legacy Cursor plans:** every paid individual plan and self-serve Cursor Teams include it. You can also link an individual SuperGrok, SuperGrok Plus, SuperGrok Heavy or X Premium+.
- **Enterprise:** ask your account team.

There's no separate Grok Bot subscription. Sign in on your phone with the same account and your access carries over. Don't buy a second subscription through the App Store or Google Play.

## How usage gets used

Usage is a weekly allowance that resets each week. On The X Subscription, Grok Bot shares it with Cursor and the Grok apps. How fast it goes depends on the work you give it and how much effort each task takes. These are the places it goes fastest:

- **<Term k="routine" text="Routines" /> that run often.** Every run uses usage, and that's the warning at the top of this page.
- **Messages between bots.** Replies in group chats and every message between bots count.
- **Test.** Testing a routine does real work, so it uses usage too. A routine that never runs uses nothing.

## Where to see what you've used

Open **Settings → Usage & Billing** and look at these sections:

- **Usage limits**: how much you've used this week, and when it resets.
- **Grok Bot usage**: a chart you can view by bot or by source.
- **Additional usage**: what you use past the weekly allowance.

The account menu can also show **Weekly usage**. Or, easier still, ask in your private chat with a bot:

<Copy id="pu-ask" code="How much Grok Bot usage have I used this week? Where does my allowance come from, and when does it reset?" />

Only the bot's owner can ask, though, and only in a private chat.

## Use less

The docs' advice is to rein in routines before moving to a bigger plan or raising a limit.

Start by pausing routines you don't need. In the bot's details, on the **Details** tab, the switch on each row pauses it. For the ones you keep, you can widen schedules and narrow triggers, like checking rentals three times a day instead of every hour. The bot can go through them for you:

<Copy id="pu-routines" code="What routines have you got set up? List them for me, with how often each one runs and what starts it. If any run too often or start on too much, tell me how you'd change them, but don't touch anything yet." />

It also helps to put fewer bots in a group, since fewer bots means fewer replies. And start big jobs small, because the more effort a task takes, the more it uses.

## When usage runs out

If a bot stops replying and says you hit your usage limit, it isn't broken. This week's allowance is used up, and it resets each week. To keep going now:

- **The X Subscription:** buy prepaid credit.
- **Legacy Cursor plans:** turn on on-demand usage.
- **Either one:** move to a bigger plan.

If you have a usage reset, go to **Resets** in **Usage & Billing**, choose **Use reset**, then **Confirm**, and this week's usage goes back to zero right away. After using one, you have to wait before you can use another.

## Set a limit so charges stop

- **The X Subscription:** at [grok.com/dashboard/billing](https://grok.com/dashboard/billing), find **Additional usage credits**. Leave **Auto top-up** off, or set a monthly additional usage limit.
- **Legacy Cursor plans:** in Grok Bot, open **Settings → Usage & Billing → On-demand monthly limit**.

<Callout type="warn" title="A limit doesn't stop work already running">
A bot in the middle of a task isn't stopped at the limit, so it can go a little past. With on-demand usage off, bots stop when the allowance runs out and continue after the weekly reset.
</Callout>

## Stuck?

<Q q="Is there a free trial?">
Some accounts can try it first. If the access screen offers **Start Trial**, choose it. The trial is a usage credit with a 7-day window, and it never turns into a paid plan. It's drawn down by how much work the bots do, not by message count, so one big task can use it all. An App Store free trial on the phone is different: it turns into a paid subscription unless you cancel first.
</Q>
<Q q="Do a Cursor plan and SuperGrok add together?">
No. On a legacy Cursor account, Grok Bot uses whichever one gives more weekly usage. Both subscriptions keep billing on their own, and buying one doesn't cancel the other.
</Q>
<Q q="The Grok app says my SuperGrok limit is used up.">
If you use Grok Bot through a linked SuperGrok, the Grok app's limit doesn't apply to Grok Bot, because they are two products with two meters. Grok Bot usage lives on your Cursor account, under **Settings → Usage & Billing** in Grok Bot.
</Q>
<Q q="Which model does it use? Can I change it?">
You can't pick it or see it. Grok Bot chooses a model for each task, and usage is recorded as Grok Bot usage. The docs give an example: routing a task to Opus 5.5 doesn't change what it costs you per token.
</Q>
