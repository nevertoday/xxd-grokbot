## 把常用的登录存进去

1. 打开 **Settings → Vault**，点 **New item**（新建）。
2. 选 **Login**（登录）、**Card**（银行卡）或 **Contact info**（联系信息）。
3. 填好保存。登录要填 **Website**（网址）、**Username or email**（用户名或邮箱）和 **Password**（密码），再点 **Save login**（保存登录）。卡可以点 **Scan with camera**（用相机扫）或 **Upload a photo**（上传照片）自动填。

在 **Hints**（提示）里写一句什么时候用，比如「工作上的采购用这张」。有好几条可选时，bot 会照着挑。

<Callout type="ok">
存好以后，密码一直是隐藏的，卡只显示后四位。存进去的值不会再显示给你看。
</Callout>

存进去的东西，你账号下所有的 bot 都能用，没法只给某一个。bot 看不到密码。它能看到你存了哪些登录，也能看到联系信息。在 Grok Bot app 的对话里，它还能看到卡号和安全码，好在结账时填。

## 从别的密码管理器搬过来

在电脑上可以一次导进来：

1. 从 1Password、Chrome 或 Edge、Safari 或 Apple 密码、Firefox、Bitwarden、LastPass 导出 CSV 文件。
2. 在 **Settings → Vault** 点 **New item**，再点 **Import from CSV…**（从 CSV 导入）。
3. 点 **Choose CSV file**（选择 CSV 文件），选刚导出的文件。文件只在你电脑上读，不会上传，要小于 5 MB。
4. 看一遍列表，再点导入按钮。已经存过的会跳过。缺密码、网址不是 https 的那几行，不会导入。

<u>导出的文件里密码没有加密，导完马上删掉。</u>

也可以连上 1Password：在 **Connect apps**（连接应用）里打开 **1Password**，点 **Connect 1Password**。之后每次登录，都要你在 1Password 里批准。这种连法在逐步开放，要 1Password 8.12.42 或更新的版本。

## 它要登录时，按这个顺序找

1. **Vault** 里存好的登录。
2. 你连的密码管理器，比如 1Password。
3. 都没有，就发一张 **Secure Form**（安全表单）问你。

表单上写着要填到哪个网站。你填的内容直接进网页，bot 看不到。想下次不用再填，就勾上 **Securely save to Bot's vault**（安全存进 bot 的 Vault）。不勾，这个值只在这段对话里用，过后自己失效。

网站发来一次性验证码时，bot 能从你连的 Gmail、Outlook 或它自己的邮箱里读到。

## 它做不了的那一步，你来接手

有些步骤要你来做，它会把电脑交给你。比如单点登录、通行密钥、过不去的验证码。另一台设备上的批准、二维码和银行卡验证也一样：

1. 在对话里那条请求上点 **Take over**（接管），或者打开电脑点 **Take control**（接手控制）。
2. 只做被卡住的那一步。
3. 点 **I'm done**（我做完了），再告诉它继续。

登录好的状态会留在电脑上，下次接着用，你所有的 bot 都能用。

<Callout type="warn" title="指纹和面容在它的电脑上用不了">
你笔记本或手机上的指纹、面容 ID、Windows Hello 和通行密钥，在它的电脑上用不了。公司应用用单点登录的，接管后换一种公司允许的方式。比如密码加验证码。在 Mac 和 Windows 上，也可以到 **Settings → General** 的 **Security Key** 下打开 **Use hardware security keys**，用硬件安全密钥。
</Callout>

## API 密钥用安全卡片

API 密钥这类东西，等 bot 发来 **secure secret card**（安全密钥卡片）再填。输入框是遮住的。点 **Save securely**（安全保存），卡片会显示 **Saved**（已保存）。值不会写进对话，bot 也看不到。

密码、验证码和 API 密钥，也别写进命令或电脑上的文件。用 **Teach a task**（教它一个任务）演示时，别在画面里输入密钥。

## 付款：想每笔都自己批，就别存卡

<mark>存在 Vault 里的卡，结账时会直接填，不会每次问你。</mark>没有哪个设置能让它每笔都先问。想每笔都自己批：

- **不存卡。** 结账时 bot 用安全表单要卡，别勾 **Securely save to Bot's vault**。这张卡只在这段对话里用，它会在对话里请你确认准确的金额。
- **已经存了就删掉。** 在 **Settings → Vault** 里选中这张卡，点 **Remove**（删除）。

<u>没有那个勾选框的表单，会直接存进 Vault。不想存卡，就别提交它。</u>

**Settings → Vault** 里还有 **Payment accounts**（付款账户），可以连 Link、X Money、Shop Pay 这类钱包。

## 卡住了？

<Q q="我存的密码在哪能看到？">
看不到。存进去的值只能写、不能读：密码一直隐藏，卡只显示后四位。要改，就在 **Settings → Vault** 里改。改卡号要先删掉，再加一次。
</Q>
<Q q="一个网站老是让我重新登录。">
接管电脑，自己登录，做完两步验证或验证码。等登录后的页面打开了，再交还给它，让它从当前页面接着做。有的网站登录很快就过期，这个没法完全避免。
</Q>
<Q q="表单显示 Could not fill into the page。">
填之前，网页可能已经跳走了。你填的内容照样没给 bot 看到。它再要的话，重新填一张新表单。
</Q>
<Q q="team bot 用不了我存的登录。">
本来就是这样，你的 Vault 不给 team bot 用。team bot 的拥有者或管理员可以给它加专用的登录。点扳手图标里的 **Manage**，到 **General** 下找 **Bot's accounts**。API 密钥加在 **Secrets** 里。
</Q>
<Q q="电脑更新以后，我的密钥没了？">
更新、**Recover**（恢复）和 **Reset**（重置）会删掉装在电脑上的应用和软件包。你写进文件或命令行配置里的密钥，可能跟着没了。用安全卡片、**Secrets** 或 Vault 存的，不受影响。
</Q>
